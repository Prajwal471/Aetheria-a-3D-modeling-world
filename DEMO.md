## 🎮 How to Use the Demo

1. **Start Exploring**
   - Open http://localhost:3000 in your browser
   - Click "Sign Up" or "Sign In" (any credentials work in demo mode)

2. **Create Your First Project**
   - Click "New Project" on the dashboard
   - Enter a project name and description

3. **Enter the 3D Editor**
   - Click on your project to open the editor
   - Use the toolbar to select tools (Move, Rotate, Scale)

4. **Add Objects**
   - Click the primitive buttons (Box, Sphere, Cylinder)
   - Or click "AI Generate" for AI-powered creation

5. **Try AI Generation**
   - Click "AI Generate" button
   - Enter prompts like:
     - "medieval castle tower"
     - "futuristic spaceship"
     - "rustic wooden cabin"
     - "crystal cave entrance"

6. **Collaborate**
   - See simulated team members in the 3D space
   - Enable voice chat (simulated)
   - Watch real-time updates

## 🔧 To Enable Full Functionality

To use real Firebase features, you'll need to:

1. **Create a Firebase Project**
   - Go to https://console.firebase.google.com
   - Create a new project

2. **Enable Services**
   - Authentication (Email/Password + Google)
   - Realtime Database
   - Storage

3. **Configure Environment**
   - Create `.env.local` file
   - Add your Firebase configuration values
   - See `CONFIGURATION.md` for detailed instructions
